# Цифровая модель 5 субпространств в 3D объёме

**Позиционирование (честно):** самосогласованная *численная* решётчатая платформа
с честным аудитом — что здесь калибровка, что стандартная формула, что настоящее
предсказание. **Не** теория, выводящая α, G, m_e из первых принципов.
Английская версия: `README_EN.md`. Препринт: `PREPRINT.md`.

Мир = 5 субпространств, каждый объёмный (20×20×20 = 8000 ячеек, тор):

| # | Субпространство | Суть |
|---|-----------------|------|
| L0 | **ВРЕМЯ** | локальная фаза и скорость течения (стрелка всегда вперёд; замедление в грав. ямах и при скорости) |
| L1 | **ЭНЕРГИЯ** | плотность энергии; строго консервативна (Нётер), снизу ограничена нулевой энергией вакуума (Казимир) |
| L2 | **ВЕРОЯТНОСТЬ** | комплексная волновая функция ψ (дискретное уравнение Шрёдингера, унитарность) |
| L3 | **ГРАВИТАЦИЯ** | потенциал [-1, 0] из плотности энергии + собственной массы узлов; всегда притягивающая |
| L4 | **ПОЛЯ** | векторное поле (3 компоненты) + заряд; упрощённый Максвелл, дипольность |

**Вакуум = раслоение** (слои не коррелированы). **Материя = узел/синтез**: ячейка, где все 5 слоёв «в фазе».
**Энтропийный регулятор**: целевая S=0.35, каждые 10 шагов давление P=clip(S−0.35)·0.02.
S > цель → «охлаждение» (порядок, синтез); S < цель → «нагрев» (раслоение, аналог тёмной энергии).

## Что это / что это не

**Что это:**
- самосогласованное решётчатое ядро (SSFM) на 5 слоях: сохранения N, p, ΣE, Σq
  проверены до ~1e-15 (131 тестов, включая бит-лок κ D12 = 0.4069113352735587);
- SI-масштабная карта: 4 якоря (U = 781.89 МэВ, α, h, dt) + 5 свободных диалов
  (аудит G4: ни один не выводится из ядра);
- машинный аудит `verification.json`: **83 проверки** — 4 калибровки, 50 стандартных
  формул (dev ≈ 0 по построению), 12 предсказаний вне калибровки, 17 честных
  решётных расчётов (D1–D18);
- 5 замороженных предсказаний P1–P5 с протоколом фальсификации (P1 уже
  фальсифицирован при β_g = 1 — зафиксирован как граница, не как опровержение);
- задокументированные «kill»-границы G1–G5: что модель **не может**.

**Что это не:**
- не теория, выводящая α, G, m_e из первых принципов — они входные
  (CODATA/PDG), как и спектр частиц;
- не новая физика: QED-совпадения (a_e +7·10⁻⁶%, R_π −0.18%, R_K +0.65%,
  p-Ps +0.65%) — формулы Стандартной модели, посчитанные через SI-карту;
- гравитационный сектор — изолированная граница (G_мод = 1.57e37 × G_физ, G1-kill);
  κ_GPS = 0.407 (−59.3% от ОТО) — честное расхождение, не объяснение;
- p-Ps: SM выше эксперимента на +0.65% (напряжение, как в o-Ps puzzle) — сходство
  не заявляется.

## Быстрый старт

Требования: Python 3.11+, numpy.

```
pip install -e .        # или без установки: python -m wm ...
wm demo                 # ~10 с: fast-гейт (68 проверок) + отчёт на английском
wm run                  # полный сценарий (20³) → snapshots.json + viewer.html
wm checks               # полный аудит: 83 проверки → verification.json + audit.html (дашборд)
wm serve                # HTTP-раздача viewer.html (файловый режим)
```

`wm demo` — витрина для внешнего читателя (отчёт на английском). Полный
английский текст доков — `README_EN.md`.

## Запуск

Код — в пакете `wm/` (Option 5); корневые `model.py` / `experiments.py` —
совместимые shim'ы (старые команды работают без изменений).

```
python model.py               # полный сценарий (20³) → snapshots.json + viewer.html
python model.py --animate     # + анимация фаз 9–11: 288 кадров (кварки → адроны → H → H2)
python -X utf8 experiments.py # 83 сверки → verification.json
```

Анимация: фазы 1–8 — как обычно (8 полных кадров), затем потоки лёгких
кадров узлов (тёмный фон, цветные точки по типу, струны): фаза 9 — каждый
шаг, фазы 10/11 — каждый 2-й. Кнопка ▶ в вьювере проигрывает всю ленту.

Или через CLI пакета (`python -m wm`, после `pip install -e .` — просто `wm`):

```
wm run    [--size N] [--seed S] [--bg D] [--out DIR] [--no-viewer]  # сценарий
wm checks [--out DIR] [--fast]                             # сверки (--fast: 68 без ЧИСЛ)
wm serve  [--out DIR] [--port P] [--host H]                # HTTP для файлового режима
wm version
```

`--bg D` — разрешение фона экспорта (D должно делить size; авто: для
size ≥ 100 — наибольший делитель ≤ 64, иначе полное разрешение).

Настройки — `config.toml` (ищется в cwd, затем в корне проекта; приоритет:
аргументы CLI > конфиг > DEFAULTS в `wm/config.py`).

Требования: Python 3.11+, numpy. Результат `run`:
- терминальный вывод: слои, срезы, ASCII-график энтропии, консервация ΣE;
- `snapshots.json` — кадры сценария (полные — бинарные смещения + узлы);
- `viewer.html` — интерактивный 3D-вьювер (данные и three.js вшиты, работает офлайн);
- `frames.bin` — только в файловом режиме (бинарник больше 32 МБ).

Тесты: `python -X utf8 -m pytest tests` (131 тестов: модель, энергия, динамика,
вьювер, конфиг, CLI (вкл. 3 demo, V2), EM/экспорт, дальняя гравитация, unified-ядро,
S5-континуум, S6-константы, квантовый H (G2), вывод β_g (G3), вывод 5 диалов (G4),
QED-прецизия (G5)). Готовый лог терминала:
`run_log.txt` (UTF-8).

## 3D-вьювер (`viewer.html`)

Открыть двойным кликом в браузере (или `wm serve` в файловом режиме).
Рендер — WebGL-шейдер: цвет каждой клетки вычисляется в vertex shader
(без per-frame JS-цикла), так что 10⁵–10⁶ клеток проигрываются плавно.
- **ЛКМ** — вращение, **колесо** — зум, **ПКМ** — панорама;
- кнопки слоёв: ВРЕМЯ / ЭНЕРГИЯ / ВЕРОЯТНОСТЬ / ГРАВИТАЦИЯ / ПОЛЯ / **МАТЕРИЯ** / **СВЕТ**;
- **КАДР** — слайдер 11 фаз + ▶ (анимация);
- **срез** X/Y/Z — рассечение объёма плоскостью;
- **стрелки полей** — топ-400 сильных клеток (направление и длина поля);
- **Режим**: «Значение» (линей/√/лог-шкала) или «Δ к пред. кадру» (дивергирующая
  палитра, симметричный диапазон) — просмотр приращений полей;
- **статистика** кадра: min/сред/σ/max отображаемых значений (+ узлов материи);
- **💾 JSON** — сохранение текущего кадра (snapshots-фрагмент) в файл;
- **фон-даунсемпл** (size ≥ 100): фоновые слои хранятся и рендерятся в
  разрешении D³ (по умолчанию 64³), а узлы/струны — точные (полное
  разрешение, цветные точки поверх фона).

## Оптимизации и масштабирование

Замеры (до/после, одна машина):

| Что | До | После |
|-----|----|-------|
| EM-взаимодействие M=1500 на 100³ | ~8 с/шаг (O(n²) Python) | +~10 мс к шагу (numpy, чанки по 512) |
| Экспорт кадра 20³ (все поля) | ~1.3 КБ JSON/ячейку | 43 байта/ячейку (float32+u8, `frames.bin`) |
| Фон 1000³ в экспорте | 10⁹ ячеек (нереально) | 50³ = 1.25·10⁵ (даунсемпл, делитель size) |

- `_update_em` — векторизован: силы чанками 512×n, тор через `mod`,
  Ейлер + writeback/crossing — O(n). Физика та же (COULOMB_K/ε из SPEC);
  аналитические тесты: сила 2 зарядов, энергетический обмен e⁺e⁻.
- Экспорт: бинарный формат (10×float32 + 3×uint8 на D³) + min/max в JSON
  для легенды; ≤32 МБ — один self-contained HTML (base64), иначе
  `frames.bin` + `snapshots.json` + `viewer.html` (нужен `wm serve`).
- Даунсемпл: фон D³ (mean/max-пулинг, D делит size), `wm run --bg D`;
  авто-режим включается при size ≥ 100. Точки/струны масштабируются на
  D-пространство, остаются точными.
- Снапшоты больших миров — в numpy-массивах (`snapshot_arrays`), без
  `tolist()` (иначе 1000³ = десятки ГБ Python-объектов).

## Сценарий (11 фаз)

Фазы 1–8 — «космический» мир (тот же мир, 810 шагов; бит-идентичная
детерминированная последовательность, закреплена `tests/test_dynamics.py`).
К t=810 чёрная дыра насыщает объём (90–100% ячеек), поэтому фазы 9–11 —
«лабораторные»: на каждую — свежий мир в чистом вакууме (детерминированно,
тот же size и seed), где показана цепочка **кварки → адроны → атом → молекула**.

1. **Вакуум** — раслоение, 20 шагов (ΣE≈170, S≈0.254, материи нет);
2. **Рождение частиц** — 3 узла во впрыске энергии; узлы живут (связность + яма ψ + собственная масса);
3. **Взаимодействие** — гравитация и поля, узлы устойчивы;
4. **Внешняя сила** — деформация в центре («ломаем дерево»);
5. **Регулятор** — 20 шагов без + 50 шагов с (сравнение энтропии);
6. **Чёрная дыра** — концентрация энергии 8.0 в (10,10,10): грав. яма до −0.99,
   локальная скорость времени падает до ~0.63 (в вакууме 1.0) — гравитационное замедление времени;
7. **Долгая эволюция** — 100 шагов, всё вместе (рост материи в яме, медленный нагрев ΣE «тёмной энергией»);
8. **Динамика частиц** — 500 шагов: спин/Pauli/бозе-стек, цепочки распадов
   τ⁻→μ⁻/π±→…→e⁻, кварковая струна u—ū (конфайнмент, разрыв при d≥4, аннигиляция при d≤1).
9. **Кварки и адроны** [лаб] — кварки u/d/ū/d̄ (параметры PDG, таблица ниже);
   `hadronize()`: тройка u,u,d → p и u,d,d → n (попарные расстояния ≤ 2 ячеек),
   в ledger — высвобождение избытка массы (≈1.19 ед. на адрон; 99% массы —
   QCD-поле, 1% — кварки); струна d—d̄ (конфайнмент). 30 шагов.
10. **Атом H** [лаб] — включается кулоновская динамика (`em_dynamics`):
   e⁻ на круговой орбите v_c = √(K/(m_e·r₀)) (симплициев Евлер, мягкое
   поле 1/√(d²+ε²)). 250 шагов: r(t) ∈ [2.8, 3.3] при r₀=3 → **СТАБИЛЕН**.
11. **Молекула H2** [лаб] — 2 протона (d₀=2) + 2 электрона в ячейке
   середины связи (разные спины → разные слоты, общий «связывающий»
   орбиталь). 250 шагов: d(p–p) ∈ [1.0, 2.0], e–p ≤ 1.0, все живы →
   **СТАБИЛЕН** (связь удержана).

### Параметры кварков (PDG 2024, решётные единицы)

| Частичка | m, МэВ | q, e | m_eff = m/m_p (масса в модели)
|---|---|---|---|
| u / ū | 2.2 | ±2/3 | 2.345e-3·m_p
| d / d̄ | 4.7 | ∓1/3 | 5.009e-3·m_p
| p (uud) | 938.3 | +1 | 1.0·m_p (1% кварки + 99% QCD-поле)
| n (udd) | 939.6 | 0 | 1.0014·m_p

Избыток массы при хадронизации (в ledger, `hadronization`):
p = 1.1884, n = 1.1868 ед. (S = 1.2/938.272 ед./МэВ). Античастицы —
инверсия заряда каталога. EM-константы: `COULOMB_K=3.6e-4`,
`COULOMB_SOFT=0.35`, v ≤ 0.95 ячейки/шаг (без RNG — детерминированно).

## Механика узла (материи)

- **Рождение**: синтез 5 слоёв > 0.4 (кристаллизация, выделение +0.1 энергии);
- **Удержание**: диффузия энергии через узел в 10 раз слабее (`NODE_BIND_STRENGTH=0.9`,
  симметрично по паре → ΣE сохраняется); амплитуда ψ «запета» к 0.7 (`PSI_NODE_AMP`);
  собственная масса создаёт яму, притягивающую энергию обратно;
- **Распад**: глубокая декогеренция (синтез < 0.15) или возраст > 250 шагов
  (`MATTER_LIFETIME`, аналог периодического распада); энергия → тепло.

PSI_NODE_AMP, ENTROPY_PRESSURE, FIELD_GAUGE) — EQUATIONS.md §12, `tests/test_s6.py` (15).

Подробный свод уравнений — **`EQUATIONS.md`** (главный артефакт).

## Частицы как узлы

`particles.py` — каталог (PDG-массы, заряды, спины, цвета, поколения,
распады, CKM). В модели: `Volume3D.particle_type` — тип узла
(`n, p, e⁻, μ⁻, τ⁻, π±, u, uū`), lifetime по типу: лог-сжатие физических τ в [50, 250] шагов
(стабильные n, p, e⁻, γ, u, uū — не распадаются). Спин ↑/↓ на узел,
2 слота/ячейка (Pauli для фермионов, бозе-стек для бозонов), цепочки
распада (τ⁻ → μ⁻/e⁻/π±, лог событий), кварковые струны (стягивание,
разрыв при d≥4, аннигиляция). Впрыск: `inject_particle(pos, symbol, spin)`,
`inject_quark_pair(pos, dist)`.
